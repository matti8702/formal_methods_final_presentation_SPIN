# formal_methods_final_presentation_SPIN

Repository for the **final presentation** of the course **Formal Methods for Software Engineering (UIC 540)** at **Politecnico di Milano** (A.Y. 2025/2026).

## Repository structure

The repository is organized into the following main folders:

- `deliverable/` → final presentation slides
- `demo/` → PROMELA models

## Project overview

This project explores the use of **formal methods** for the verification of concurrent systems through **model checking** with **SPIN**. For the demo, we modeled the **Dining Philosophers** problem in PROMELA.
